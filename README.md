# Hybrid-BCI-for-Effective-Decision-Communication
> **Accepted at the IEEE International Conference on Systems, Man, and Cybernetics (SMC), 2026**
## Short Summary

This work presents an asynchronous hybrid Brain–Computer Interface (BCI) that combines **eye tracking and motor imagery (MI)** for effective decision communication. Eye tracking enables direct target selection, while MI provides confirmation of the selected command. The study investigates the effects of visual fixation and EEG channel configuration using data from 15 healthy participants.

## Data Acquisition

EEG data were acquired from **15 healthy participants** using a **g.Nautilus research-grade wireless EEG headset** with 16 electrodes.

- **Participants:** 15 healthy participants
- **Age:** 20–26 years
- **EEG Channels:** 16
- **Sampling Frequency:** 500 Hz
- **Electrode Placement:** Standard 10–20 system
- **Paradigms:** Conventional Motor Imagery (MI) and Hybrid Eye-Tracking + MI
- **Conditions:** Fixation ON and Fixation OFF

Three EEG channel configurations were evaluated:

1. **All Channels:** Full 16-channel montage
2. **Motor Cortex:** C3, Cz, C4
3. **Extended Motor Cortex:** F3, Fz, F4, P3, Pz, P4, C3, Cz, C4

The EEG data were segmented according to the experimental events and used for subsequent preprocessing, feature extraction, and classification.
